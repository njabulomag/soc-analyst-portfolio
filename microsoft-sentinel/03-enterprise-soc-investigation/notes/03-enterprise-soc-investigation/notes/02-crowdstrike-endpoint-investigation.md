# Step 2 – CrowdStrike Endpoint Investigation

## Objective

Investigate endpoint alerts generated by CrowdStrike Falcon to identify suspicious activity, determine alert severity, and understand attacker behavior using the MITRE ATT&CK framework.

## Query Used

[02-crowdstrike-endpoint-investigation.kql](../queries/02-crowdstrike-endpoint-investigation.kql)

## Query

```kql
CrowdStrikeAlerts
| project
    TimeGenerated,
    Name,
    SeverityName,
    Tactic,
    Technique,
    DisplayName
| order by TimeGenerated desc
```

## Findings

The query returned **53 CrowdStrike endpoint alerts**.

The investigation identified multiple high-risk detections including:

- Credential Dumping
- NetworkConnect C2
- C2 Beacon Detected
- Malicious PowerShell Execution
- Security Tool Tamper
- Ransomware Behavior
- Sensitive File Staging

The alerts mapped to several MITRE ATT&CK tactics including:

- Execution
- Credential Access
- Defense Evasion
- Collection
- Command and Control
- Impact

The most critical finding was **Ransomware Behavior**, which represents the **Impact** phase of the MITRE ATT&CK framework. This indicates that if the activity were genuine, the attacker would likely have progressed through multiple attack stages before attempting to encrypt data.

The investigation also highlighted how multiple endpoint alerts can be correlated to understand the progression of an attack rather than treating each alert as an isolated event.
