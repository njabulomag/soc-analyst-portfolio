# Content Hub Configuration

## Overview

Microsoft Sentinel Content Hub provides a centralized repository for Microsoft and community-developed security solutions. These solutions extend Microsoft Sentinel by deploying analytics rules, hunting queries, workbooks, automation, threat intelligence, watchlists, parsers, and other security content into the workspace.

This document describes the Content Hub configuration reviewed during this implementation.

---

## Environment

| Setting         | Value                  |
| --------------- | ---------------------- |
| Platform        | Microsoft Sentinel     |
| Feature         | Content Hub            |
| Environment     | Microsoft Sentinel Lab |
| Solution Status | Installed              |

---

## Installed Solutions

The following solutions were installed within the Microsoft Sentinel workspace:

| Solution                      | Purpose                                                         |
| ----------------------------- | --------------------------------------------------------------- |
| Amazon Web Services           | Integrates AWS security telemetry and monitoring.               |
| Azure Activity                | Collects Azure Activity Logs for monitoring and investigations. |
| Log4j Vulnerability Detection | Detects activity associated with Log4j vulnerabilities.         |
| Microsoft Defender for Cloud  | Provides cloud security monitoring and protection.              |
| Microsoft Defender XDR        | Correlates incidents across Microsoft Defender products.        |
| Microsoft Entra ID            | Adds identity-related detections and monitoring.                |
| Network (Preview)             | Extends network visibility and monitoring capabilities.         |
| Security Threat Essentials    | Deploys foundational security monitoring content.               |
| Sentinel SOAR Essentials      | Provides automation and orchestration content.                  |
| SOC Handbook                  | Community guidance and operational documentation.               |
| Threat Intelligence (NEW)     | Extends threat intelligence capabilities.                       |
| UEBA Essentials               | Enables User and Entity Behavior Analytics (UEBA).              |
