# Analytics Rules Configuration

## Overview

This implementation guide documents the deployment and validation of Microsoft Sentinel Analytics Rules used to detect suspicious activity across the monitored environment.

The objective is to configure reliable detections that generate alerts and incidents for Security Operations Center (SOC) analysts.

## Custom Analytics Rule

Rule Name:

Multiple Failed Windows Logons

Detection Type:

Scheduled Query Rule

Severity:

Medium

MITRE ATT&CK

Tactic:

Credential Access

Technique:

Brute Force (T1110)

---

## Data Source

SecurityEvent

---

## Detection Logic

The rule monitors Windows Security Event ID 4625 and identifies user accounts generating ten or more failed authentication attempts during the configured query interval.

This detection assists SOC analysts in identifying brute-force attacks, password spraying, and other authentication-based attacks.

---

## Incident Configuration

The analytics rule is configured to automatically create Microsoft Sentinel incidents whenever the detection criteria are satisfied.

Alerts generated by this rule are grouped into a single incident to simplify investigation.
